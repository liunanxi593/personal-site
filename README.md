# Nancy Liu — Portfolio

A personal portfolio of visual design and human–computer interaction work.

Website: https://liunanxi593.github.io/personal-site/

The site uses static HTML, CSS, JavaScript, and original project media. GitHub Pages serves the website from the root of the main branch.

- `index.html`: personal introduction
- `projects.html`: six-project overview
- `project-*.html`: project details

Unused source media and earlier project assets are excluded from publication through `.gitignore`.
